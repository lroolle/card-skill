* What happened

** The build is 9 minutes slower because the cache key changed
:PROPERTIES:
:CUSTOM_ID: cache-key
:BASIS: fact
:END:
Every nightly since 2026-09-12 misses the dependency cache and rebuilds it from scratch.

- before :: 14 min median
- after :: 23 min median
- cache hit rate :: 96% to 0%

** A toolchain bump on 2026-09-12 put its version into the cache key
:PROPERTIES:
:CUSTOM_ID: toolchain
:BASIS: fact
:FROM: cache-key
:END:
The new toolchain writes a patch version into the lockfile hash. The patch version changes on every runner image update.

** Runner size and test count are ruled out
:PROPERTIES:
:CUSTOM_ID: ruled-out
:BASIS: inference
:END:
Runner size did not change. The test count grew by 2%, which explains seconds, not minutes.

* What it means

** Pinning the cache key to the minor version restores the old time
:PROPERTIES:
:CUSTOM_ID: pin-key
:BASIS: inference
:FROM: cache-key toolchain
:END:
The minor version only changes on a deliberate upgrade, so the cache stays valid between upgrades. See [[#toolchain]] for the cause.
