Agent 用卡片回答，你逐张判断。

给 Claude Code 这类编程 Agent 用的技能。Agent 把回答摆成一个看板，一张卡片只说一个结论，最多带一个提问。回复是结构化数据，一张卡片一行，传回给 Agent。

比较三个消息队列，给接入服务用，让我来选。用卡片回答。

技能里写了什么时候值得用看板，什么时候直接说更好。多数回答还是该用文字。

需要 Node 18 及以上，没有其他依赖。复制的那一份不会自己更新，拉取新版本后再复制一次。node ~/.claude/skills/{{NAME}}/bin/cards.mjs --version 能看到当前版本。

它不做的事

  • 一个回答就够的事，用不上它。一段话能说清的事，用看板是小题大做。有好几件事要判断，有只能你来拿的主意，或者工作要跨好几轮，才用它。
  • 没在手机真机上测过。测试只在电脑上的 Chromium、Firefox 和 WebKit 里跑。没验证的都列在 STATUS.md。
  • 没有云端服务。看板就是你磁盘上的一个文件。发布出去的看板是静态页面，读的人把回复复制下来发给你。
